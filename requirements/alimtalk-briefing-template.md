# 월간 사고현황 브리핑 — 카카오 알림톡 템플릿 문안 (검수 제출용 초안)

> 카카오 비즈니스 채널 → 알림톡 → 템플릿 등록 시 아래 문안을 사용.
> 알림톡은 **정보성**(광고 아님)이며 변수는 `#{변수명}` 형식. 상세 브리핑은 대시보드 링크로 연결.
> 발신프로필(sender key)·template_id 승인 후 백엔드 env로 주입(`ALIMTALK_SENDER_KEY`, `ALIMTALK_TEMPLATE_BRIEFING`).

---

## 템플릿 유형: 기본형 + 웹링크 버튼

### 템플릿 본문
```
[다이소 안전보건] #{기간} 사고현황 브리핑

#{조직명} 안전현황을 전해드립니다.

▶ #{기간} 발생: #{건수}건 (목표 대비 #{목표대비})
▶ 전년 동월 대비: #{전년대비}
▶ 최다 재해유형: #{핵심유형}

상세 현황·예방 조치는 아래 버튼에서 확인하세요.
```

### 버튼
| 버튼명 | 유형 | 링크 |
|---|---|---|
| 우리 조직 현황 보기 | 웹링크(WL) | `#{대시보드링크}` (조직 스코프 딥링크) |

---

## 변수 정의 (백엔드가 채움)

| 변수 | 예시 | 산출 |
|---|---|---|
| `#{조직명}` | "수도권영업부문" / "강남/구리영업부" / "일산팀" / "고양화정점" | 수신자 스코프(부문/부서/팀/매장) |
| `#{기간}` | "2026년 6월" | 전월 |
| `#{건수}` | "12" | org_rollup 해당 스코프 전월 사고건수 |
| `#{목표대비}` | "▲2건 초과" / "▼1건 감축" / "목표 달성" | kpi_targets 대비(kpiProgress) |
| `#{전년대비}` | "+3건(+33%)" / "−2건(−15%)" | YoY |
| `#{핵심유형}` | "넘어짐 (5건)" | 해당 스코프 최다 재해유형 |
| `#{대시보드링크}` | `https://.../#tab=dept&scope=강남구리영업부` | 조직 스코프 딥링크 |

## 설계 메모
- **알림톡 = 요약+링크**, 상세 AI 브리핑(헤드라인+3부+인사이트카드)은 대시보드/브리핑 페이지에 렌더(알림톡 템플릿에 장문 AI 텍스트는 부적합).
- 한 템플릿으로 전 조직레벨 커버(`#{조직명}`만 다름). 필요 시 부문장용/현장용 2종으로 분화 가능.
- 광고성 표현·이모지 남용 금지(검수 반려 사유). "▶/▲/▼"는 텍스트 기호라 허용 범위.
- 발송 대상은 `recipients.json`의 `users` 맵(수신 동의·연락처 보유자)에 한함. 미승인 전까지 `NOTIFY_CHANNEL=mock`으로 개발.
